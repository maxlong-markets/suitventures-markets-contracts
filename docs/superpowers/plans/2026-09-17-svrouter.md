**Goal:** The `SVRouter` contract for M2, built in Foundry, with a unit suite covering 100 % of its lines, statements, branches and functions and a fork suite against the real pools, ready for Kobe's line-by-line review before any deployment.

## Global Constraints

- Addresses, pool keys and behaviour exactly as the spec's sections 2 to 5. The Universal Router is the current one, `0x06afBA43fd06227fA663b0dAeCF536F6eaA6BF99`; Permit2 `0x000000000022D473030F116dDEE9F6B43aC78BA3`.
- The fee is taken from the input token before the swap; `MAX_FEE_BPS = 50`; deploy values `feeBps = 50`, `holderFeeBps = 0`; `setFees` requires `feeBps <= 50` and `holderFeeBps <= feeBps`.
- The router grants no allowance to anyone, holds no token after a swap, and sends the output straight to the user (`TAKE` with the user as recipient). Exact input only.
- Command and action bytes come from the installed `universal-router` (`Commands.sol`) and `v4-periphery` (`Actions.sol`, `ActionConstants.sol`) libraries; no hand-written constants for them.
- Coverage bar: `forge coverage` reports 100 % lines, statements, branches and functions for `src/SVRouter.sol` from the unit suite alone (no RPC). Fork tests are skipped, not failed, without `ROBINHOOD_RPC_URL`.
- No private key, RPC key or address of Kobe's wallets in the repo; `.env.example` carries placeholders only; `.env` is git-ignored. Fork tests use `vm.addr` keys and the public RPC.
- Gates after every task: `forge fmt --check`, `forge build`, `forge test` (unit), `forge coverage --report summary` (Task 2 onward), and `forge test --match-path 'test/fork/*'` with the RPC when the task touches fork tests.

### Task 1: Project scaffold and the SVRouter contract (Fable)

**Files:** Create everything under "File structure" except the unit and fork test suites; `test/unit/SVRouter.smoke.t.sol` proves the contract deploys and completes one swap through the mock router.

**Interfaces:** Produces `ISVRouter` exactly as spec section 3 (names, types, order of parameters), `SVRouter` implementing it per spec sections 4 and 5, the three mocks with these surfaces: `MockERC20(name, symbol, decimals)` with `mint(to, amount)`; `MockERC721` with `mint(to, id)`; `MockUniversalRouter(address poolManagerPlaceholder)` with `setOutput(address tokenOut, uint256 amount)` (what it pays the recipient on the next call), `setRevert(bytes revertData)` (revert with that data on the next call), `lastCommands()`, `lastInputs()`, `lastDeadline()` recording the last `execute` call, and an `execute(bytes commands, bytes[] inputs, uint256 deadline)` that reverts unless `commands` is exactly the V4_SWAP byte, decodes `inputs[0]` into actions and params, checks the three actions are SWAP_EXACT_IN_SINGLE, SETTLE, TAKE in that order, checks the SETTLE currency equals the swap's input currency and `payerIsUser == false`, checks the TAKE recipient is the caller's user (passed in the params), pulls its own balance of the input currency (it must equal the swap's `amountIn`), and transfers the configured output of `tokenOut` to the TAKE recipient (minting through `MockERC20.mint`).

### Task 2: Unit suite to 100 % coverage (Opus writes, Sonnet runs)

**Files:** `test/unit/SVRouter.t.sol`, `test/unit/SVRouter.fuzz.t.sol`; may extend the mocks.

Cases (each its own test function, named for the behaviour): constructor zero-address reverts (four) and the stored values; `setFeeWallet` (event, zero reverts, only owner); `setFees` (event, `feeBps > 50` reverts, `holderFeeBps > feeBps` reverts, raising back to 50 after lowering is allowed, only owner); `setSuitsNft` (event, zero allowed, only owner); `Ownable2Step` two-step transfer; `feeFor` with no NFT, with NFT and zero balance, with NFT and a balance, rounding down on odd amounts; `swapExactIn` happy path both directions with exact `Trade` values, fee arithmetic against the fee wallet balance, net amount reaching the mock router, output at the user, router balances unchanged; `Expired`, `ZeroAmount`, `PermitMismatch` on token and on amount, Permit2's own revert on a bad signature and on a reused nonce, `InsufficientOutput` when the mock pays less than the minimum, the mock's configured revert bubbling up (slippage from the Universal Router), holder rate at 0 bps and at a non-zero configured rate, `sweep` (only owner, moves a token sent by mistake); fuzz: `amountIn` in `[1, 2**120]` and `feeBps` in `[0, 50]` with `holderFeeBps <= feeBps`, asserting `fee == amountIn * bps / 10_000`, `fee + net == amountIn`, and `fee <= amountIn / 200`. The runner (Sonnet) executes `forge test` and `forge coverage --report summary --report lcov` and reports every uncovered line and branch of `src/SVRouter.sol`; the writer (Opus) closes the gaps; repeat until the file reads 100 % on all four columns. Commit: `Unit tests: full coverage of SVRouter` plus the trailer.

### Task 3: Fork suite (Opus writes, Sonnet runs)

**Files:** `test/fork/SVRouterFork.t.sol`, `test/utils/*` as needed.

`setUp` skips (`vm.skip(true)`) when `ROBINHOOD_RPC_URL` is unset; otherwise `vm.createSelectFork` at a pinned block (the block current when the suite is written, recorded in the file), deploys the router against the real Universal Router and Permit2 with a `MockERC721` as the Suits NFT and a test fee wallet, funds a test user with NVDA (`deal`, falling back to `vm.prank` of the PoolManager's balance if `deal` cannot find the slot), and has the user approve Permit2 once. Cases: MARIO/NVDA buy and sell, microduck/NVDA buy and sell (reversed currency order), AI/NVDA buy with a dust amount (the pool has about 0.014 NVDA of liquidity), each asserting: fee arrived in the fee wallet, user received at least the V4 Quoter's `quoteExactInputSingle` for the net amount minus 1 % slippage, `Trade` event values, router balances zero after; a holder run (NFT minted) paying 0 fee; `amountOutMin = type(uint128).max` reverting; a second use of the same Permit2 nonce reverting. Runner (Sonnet) runs `forge test --match-path 'test/fork/*' -vv` with the RPC and reports; the writer fixes.
